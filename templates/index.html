A. Caso: proceso de postulación laboral

Problema que se busca resolver

Las agencias de selección reciben postulaciones laborales con información que puede estar incompleta, desordenada o presentar formatos incorrectos. Esto dificulta su revisión inicial.

Esta aplicación utiliza una plantilla estándar para recibir los datos del postulante, convertirlos a un lenguaje específico del dominio (DSL) y comprobar su estructura mediante un mini compilador.

Flujo del proceso empresarial

1. Recepción de plantilla 2. Conversión al DSL 3. Análisis léxico y sintáctico 4. Resultado para Recursos Humanos

El analizador léxico identifica los lexemas de la postulación y los clasifica en categorías de tokens mediante expresiones regulares.

Relación entre tokens, expresiones regulares y autómatas

Los autómatas finitos se construyen a partir de las reglas de reconocimiento de los tokens del lenguaje DSL. Cada token agrupa lexemas que cumplen un patrón. Algunos valores utilizan restricciones específicas según el campo donde aparecen.

Token agrupador Lexema o contexto Regla de reconocimiento Autómata relacionado
TK_SECCION DATOS_PERSONALES, EDUCACION, EXPERIENCIA DATOS_PERSONALES|EDUCACION|EXPERIENCIA Palabras reservadas de sección
TK_CAMPO NOMBRE, DNI, CORREO, INSTITUCION, PUESTO NOMBRE|DNI|CORREO|INSTITUCION|PUESTO Identificadores reservados de campo
TK_DNI 12345678 [0123456789]{8} AFND y AFD de DNI
TK_CORREO juan@gmail.com Usuario + @ + dominio + extensión AFND y AFD de CORREO
TK_TEXTO NOMBRE: Juan Perez Letras y espacios AFND y AFD de NOMBRE
TK_TEXTO INSTITUCION: Universidad 2026 Letras, números, espacios y signos admitidos AFND y AFD de INSTITUCION
TK_TEXTO PUESTO: Analista de Software 2 Letras, números, espacios y signos admitidos AFND y AFD de PUESTO
TK_LLAVE {, } [{}] Delimitador de bloque
TK_DOS_PUNTOS : Símbolo literal separador Separador de campo y valor

TK_TEXTO es una categoría léxica agrupadora. Los campos NOMBRE, INSTITUCION y PUESTO comparten esta categoría, pero sus valores se validan mediante patrones específicos. Los autómatas visualizados corresponden a esas reglas de validación.

3.2 Análisis sintáctico

La gramática libre de contexto establece el orden de las secciones y los campos obligatorios de la postulación.

Gramática del lenguaje

G = (V, T, P, S)

V = {S, DP, ED, EX, CN, CD, CC, CI, CP}

S es el símbolo inicial.

Los terminales corresponden a las secciones, identificadores, delimitadores y valores reconocidos por el analizador léxico.

No terminal Producción
S DP ED EX
DP DATOS_PERSONALES { CN CD CC }
ED EDUCACION { CI }
EX EXPERIENCIA { CP }
CN NOMBRE : TK_TEXTO
CD DNI : TK_DNI
CC CORREO : TK_CORREO
CI INSTITUCION : TK_TEXTO
CP PUESTO : TK_TEXTO
