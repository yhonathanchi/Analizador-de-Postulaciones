Sistema de validación estructural de postulaciones laborales

A. Caso

Enunciado del proyecto

Las agencias de selección reciben postulaciones laborales que pueden presentar errores de formato, campos incorrectos o información estructurada de distintas maneras.

Nuestra solución propone reconocer los componentes de un lenguaje formal para postulaciones laborales mediante tokens, lexemas y expresiones regulares.

Ingreso de datos

Selecciona una forma de introducir la postulación:

Seleccionar archivo

Selecciona un archivo de texto con los campos definidos por nuestro lenguaje.

Escribir una postulación

Escribe los datos utilizando el formato del ejemplo.

Ejemplo de nuestro lenguaje

DATOS_PERSONALES {
NOMBRE: Juan Perez
DNI: 12345678
CORREO: juan@gmail.com
}

EDUCACION {
INSTITUCION: Universidad de Lima
}

EXPERIENCIA {
PUESTO: Asistente administrativo
}

El lenguaje utiliza las secciones DATOS_PERSONALES, EDUCACION y EXPERIENCIA. Este es un ejemplo de entrada y no un currículum completo.

3.1 Análisis léxico

El analizador identifica lexemas y los clasifica en tokens mediante expresiones regulares.

Reglas y expresiones regulares

Campo Expresión regular Ejemplo válido Descripción
DNI [0-9]{8} 12345678 Exactamente ocho dígitos
CORREO [A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Za-z]{2,} juan@gmail.com Formato básico de correo electrónico
NOMBRE [A-Za-zÁÉÍÓÚáéíóúÑñÜü ]+ Juan Perez Letras y espacios

Σ representa todos los símbolos del alfabeto indicado en la quíntupla. ε representa una transición sin consumir caracteres. Las transiciones se agrupan por destino. Los símbolos no definidos se rechazan.
